Lo skew, di nuovo

La v1 era tutta skewY. Qui lo skew resta solo sui dettagli (muro, maniglie, blocchi), per farli combaciare con l'angolo del vetro. 

/* il muro si inclina dell'angolo del lato */
.wall.left   { transform: skewY(var(--angle-left-deg)) rotateY(180deg); }

/* la maniglia segue, ma più morbida */
.handle.left { transform: skewY(calc(var(--angle-left-deg) * 0.2)); }

/* i blocchi compensano anche l'angolo isometrico di base */
.blocks-container.right {
  transform: skewY(calc(var(--angle-right-deg) * -1 + 1deg * var(--base-skew-angle)));
}
