Layout guidato dal CSS

Il JS calcola solo i numeri e li butta in custom property. Il layout lo fa il CSS con calc(): niente attributi settati a mano. 

// buildCanvasStyle.ts: JS → decine di custom property
return {
  "--base-front-x-px":             `${Math.round(points.base.front.x)}px`,
  "--glass-left-bottom-left-x-px": `${Math.round(points.glass.left.bottomLeft.x)}px`,
  "--angle-left-deg":              `${dimensions.skewAngleLeft.value}deg`,
  // …e così via, tutta la geometria
}
/* il CSS posiziona tutto leggendo le variabili */
.wall.left {
  width:  calc(var(--base-front-x-px) - var(--glass-left-bottom-left-x-px));
  height: calc(var(--tray-front-y-px) - var(--glass-left-bottom-right-y-px));
  transform: skewY(var(--angle-left-deg)) rotateY(180deg);
}
