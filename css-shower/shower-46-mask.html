La mask: sfumare, non tagliare

Le pareti dietro la doccia non hanno un bordo netto: una mask a radial-gradient le fa sfumare verso i lati (vignette). 

.noise-overlay {
  background-image: var(--noise-texture);
  /* la maschera rende trasparenti i bordi: sfuma, non taglia */
  mask: radial-gradient(circle, black 50%, transparent 70%);
}
